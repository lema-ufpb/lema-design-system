# Welcome to LEMA-DS <small className="text-muted-foreground text-base font-normal">v{VERSION}</small> 🚀

**LEMA-DS** is the official design system and component library for the [Laboratório de Economia e Modelagem Aplicada (LEMA)](https://lema.ufpb.br) at Universidade Federal da Paraíba (UFPB). It provides a modern, accessible, and themeable set of React components built on shadcn/ui and Radix UI Primitives.

> **Registry:** `325` items (`261` `ds-*` + `62` primitives + `3` libs) — `316` specs in `docs/specs/` — `250+` `components/ds` composites — consumable via `npx shadcn@latest add ds-<name>` → `components/ui/ds-<name>.tsx`.

## 🛠️ The Stack

- **[React 19](https://react.dev/)**: Core UI library.
- **[Next.js 16](https://nextjs.org/)**: Application framework.
- **[TypeScript](https://www.typescriptlang.org/)**: End-to-end type safety.
- **[Tailwind CSS v4](https://tailwindcss.com/)**: Utility-first styling (`@theme inline`, no `tailwind.config.js`).
- **[Radix UI](https://www.radix-ui.com/)**: Headless accessibility primitives (base `radix`, style `luma`).
- **[shadcn/ui](https://ui.shadcn.com/)**: Base component layer (`components/ui` — 62 primitives, never edit manually).
- **[class-variance-authority](https://cva.style/)**: Type-safe `cva()` variants with `defaultVariants`.
- **[Storybook 10](https://storybook.js.org/)**: Documentation + Vitest browser mode (`make test`).
- **[Vitest](https://vitest.dev/)**: Unit + a11y testing.

## 🏗️ Library Structure

The library is organized into three layers:

### 1. Foundation

The core "DNA" — semantic tokens, typography, color palette, and theme configuration.

- **Color Tokens**: `--background`, `--foreground`, `--primary`, `--muted`, `--border`, and dark-mode counterparts.
- **Risk Tokens**: `--risk-1` … `--risk-4` for data visualization.
- **Highlight/Chart Tokens**: `--highlight-violet/sky/white`, `--chart-1` … `--chart-5` (never raw hex).
- **Theme Support**: Light / Dark / System via `ToggleTheme` + `next-themes`.
- **Internationalization (i18n)**: Centralized in `lib/ui-i18n.ts` (`en-US`, `pt-BR`, `es-ES`, `fr-FR`) — `locale` prop auto-installs `ui-i18n` registry dependency.

## 📦 Installing Components

### Via `@lema-ufpb/ds-sync` (recommended for UFPB projects)

```bash
npm install -D @lema-ufpb/ds-sync
```

`.env.local`:

```env
LEMA_DS_TOKEN=<your-token>
LEMA_DS_REGISTRY=https://ds.lema.ufpb.br
```

```bash
npx ds add dashbox bar-chart
npx ds add ds-tilt-card ds-spotlight-card
npx ds verify
npx ds sync --all --yes
```

> 🔑 Token via LEMA NOC. `ds.lock` must be committed.

### Via shadcn CLI

```bash
npx shadcn@latest add ds-card-stat
npx shadcn@latest add ds-hero-layers
npx shadcn@latest add ds-dashboard
```

> `lib/ui-i18n.ts` auto-installs as `registry:lib` dependency for locale-aware components.

## 🌐 Internationalization

Four locales via `UI_I18N[locale]` (`lib/ui-i18n.ts`):

| Code  | Language           |
| ----- | ------------------ |
| en-US | English (default)  |
| pt-BR | Português (Brasil) |
| es-ES | Español            |
| fr-FR | Français           |

```tsx
import { Dashbox } from "@/components/ds/dashbox"
;<Dashbox title="Status" locale="pt-BR" status="live" />
// → "Online", "Atualizar", "Recolher"
```

`locale` defaults to `en-US`. Extend by adding entry to `UI_I18N`.

## 🌟 Key Features

- **Accessibility**: WAI-ARIA, keyboard nav, `prefers-reduced-motion` fallbacks, `axe` checks in Vitest. [Accessibility Statement](/docs/ui-accessibility--docs) (WCAG 2.1 AA).
- **Themes**: Semantic tokens (`bg-primary`, `text-muted-foreground`, `bg-success`, `bg-risk-1`…`4`, `bg-muted`) auto-adapt light/dark, no manual `dark:` overrides.
- **Responsiveness**: Mobile-first, `@container` queries, `SidebarProvider` responsive.
- **Type Safety**: 100% TypeScript + CVA `VariantProps`.
- **Spec-First**: Every `components/ds/*.tsx` has `docs/specs/ds-*.md` + colocated `.stories.tsx` — `316` specs total.
- **Registry-Ready**: `325` items in `registry.json`, `public/r/*.json` via `make registry`.
