# Welcome to LEMA-DS <small className="text-muted-foreground text-base font-normal">v{VERSION}</small> 🚀

**LEMA-DS** is the official design system and component library for the [Laboratório de Economia e Modelagem Aplicada (LEMA)](https://lema.ufpb.br) at Universidade Federal da Paraíba (UFPB). It provides a modern, accessible, and themeable set of React components built on shadcn/ui and Radix UI Primitives.

## 🛠️ The Stack

- **[React 19](https://react.dev/)**: Core UI library.
- **[Next.js 16](https://nextjs.org/)**: Application framework.
- **[TypeScript](https://www.typescriptlang.org/)**: End-to-end type safety.
- **[Tailwind CSS v4](https://tailwindcss.com/)**: Utility-first styling engine.
- **[Radix UI](https://www.radix-ui.com/)**: Headless accessibility primitives.
- **[shadcn/ui](https://ui.shadcn.com/)**: Base component layer.
- **[class-variance-authority](https://cva.style/)**: Type-safe component variants.
- **[Storybook](https://storybook.js.org/)**: Component documentation.
- **[Vitest](https://vitest.dev/)**: Unit testing.

## 🏗️ Library Structure

The library is organized into three layers:

### 1. Foundation

The core "DNA" of the design system — semantic tokens, typography, color palette, and theme configuration.

- **Color Tokens**: `--background`, `--foreground`, `--primary`, `--muted`, `--border`, and their dark-mode counterparts.
- **Risk Tokens**: Custom semantic tokens (`--risk-1` to `--risk-4`) for data visualization and risk indicators.
- **Theme Support**: Seamless switching between Light, Dark, and System modes via `ToggleTheme`.
- **Internationalization (i18n)**: All UI strings are centralized in `lib/ui-i18n.ts` and localized via an optional `locale` prop (`"en-US"`, `"pt-BR"`, `"es-ES"`, `"fr-FR"`). Each component auto-installs the i18n dictionary as a registry dependency.

### 2. Shadcn UI Primitives

Atomic, accessible base components installed via the shadcn CLI — used as building blocks for the custom layer above.

- **Form**: [Button](/docs/shadcn-ui-button--docs), [Input](/docs/shadcn-ui-input--docs), [Input Group](/docs/shadcn-ui-inputgroup--docs), [Textarea](/docs/shadcn-ui-textarea--docs), [Badge](/docs/shadcn-ui-badge--docs), [Questionnaire](/docs/shadcn-ui-questionnaire--docs)
- **Overlay**: [Dialog](/docs/shadcn-ui-dialog--docs), [Drawer](/docs/shadcn-ui-drawer--docs), [Dropdown Menu](/docs/shadcn-ui-dropdownmenu--docs), [Popover](/docs/shadcn-ui-popover--docs), [Tooltip](/docs/shadcn-ui-tooltip--docs)
- **Display**: [Avatar](/docs/shadcn-ui-avatar--docs), [Accordion](/docs/shadcn-ui-accordion--docs), [Card](/docs/shadcn-ui-card--docs), [Progress](/docs/shadcn-ui-progress--docs), [Skeleton](/docs/shadcn-ui-skeleton--docs), [Spinner](/docs/shadcn-ui-spinner--docs), [Table](/docs/shadcn-ui-table--docs)
- **Chat**: [Attachment](/docs/shadcn-ui-attachment--docs), [Bubble](/docs/shadcn-ui-bubble--docs), [Marker](/docs/shadcn-ui-marker--docs), [Message](/docs/shadcn-ui-message--docs), [MessageScroller](/docs/shadcn-ui-messagescroller--docs)
- **Layout**: [Scroll Area](/docs/shadcn-ui-scrollarea--docs), [Command](/docs/shadcn-ui-command--docs)
- **Navigation**: [Pagination](/docs/shadcn-ui-pagination--docs)

### 3. Custom UI Components

Custom components live in `components/ds/`. Shared utilities and helpers in `lib/` provide CVA variants, i18n dictionaries, and formatting utilities reused across the component family. Each component is individually registered in `registry.json` (type `registry:ui`), with barrel entries listing sub-components as `registryDependencies`. Install individually or in bulk via the [LEMA registry](https://ds.lema.ufpb.br/r/registry.json).

#### Actions

- **[Button](/docs/actions-button--docs)**: Feature-rich button with loading state, start/end icons, `rounded` variant (`full`/`lg`/`md`/`none`), `fullWidth`, double-click debounce, two-step destructive confirmation, and built-in tooltip via Radix. Wraps the shadcn `Button` primitive.
- **[IconButton](/docs/actions-iconbutton--docs)**: Icon-only button with optional tooltip, loading state, and configurable size and rounding.
- **[ToggleTheme](/docs/actions-toggletheme--docs)**: Dropdown button to switch between light, dark, and system themes. Re-exports `ThemeProvider` and `useTheme` from `@/providers/theme` for app-level setup.

#### Layout & Containers

- **[Dashrow](/docs/ui-dashrow--docs)**: Responsive layout container for dashboard panels with resizable split ratios and N-child support.
- **[Dashbox](/docs/ui-dashbox--docs)**: Structured dashboard card with collapse/expand, fullscreen, refresh, loading skeleton, and status badge.
- **[DrawerUI](/docs/ui-drawerui--docs)**: Full-featured drawer wrapper with header, scrollable body, footer, direction-aware close button, snap points, scale background, and event handlers for escape/pointer-down-outside. Supports bottom, left, right, and top directions.
- **[Modal](/docs/ui-modal--docs)**: Flexible modal dialog built on Dialog with 6 size variants, 5 intent colors, defaultOpen for uncontrolled usage, scrollable body, auto async confirm tracking, loading skeleton, escape/pointer-down-outside/interact-outside event handlers, and i18n support.

#### Data Display

- **[CardStats](/docs/data-display-cardstats-dashboard--docs)**: Portfolio of 9 KPI card variants — CardStat, CardStatCompact, CardStatProgress, CardStatComparison, CardStatSparkline, CardStatHighlight, CardStatList, CardStatGauge, CardStatHeatbar. All share CVA variants from `lib/card-stats-shared.tsx`. Each variant is installable individually (`card-stat`, `card-stat-compact`, etc.) or all at once via the `card-stats` barrel (which lists all variants as `registryDependencies`).
- **[MiniCard](/docs/data-display-minicard--docs)**: Compact stat label+value unit for horizontal summary strips. Compose with MiniCardGroup (pill, outlined, elevated, ghost) and MiniCardStrip (auto-dividers). Supports icons, sub-values, intent colors, delta indicators, and number formatting. Size propagates via context.
- **[DataTable](/docs/data-display-datatable--docs)**: High-performance virtualized data table with built-in toolbar, pagination, sorting, and `locale` prop for automatic i18n label resolution (search placeholder, empty state, pagination labels).
- **[Avatar](/docs/data-display-avatar--docs)**: Extended avatar with 5 sizes, status dots, initials color generator, image loading status callback, delay fallback, group overflow, tooltip, and skeleton loading.
- **[Badge](/docs/data-display-badge--docs)**: Extended badge with dot indicator, removable close icon, icon support, counter/overflow display, and semantic color variants (success/warning).

#### Charts

Data visualization components built on Recharts (and pure SVG for Boxplot) and tailored for the LEMA design system.

- **[BarChart](/docs/data-display-barchart--docs)**: Bar chart with tooltips, legend, stacking, rounded corners, and brush zoom.
- **[BoxplotChart](/docs/data-display-boxplotchart--docs)**: Custom SVG box-and-whisker chart with notch support and outlier plotting.
- **[CandlestickChart](/docs/data-display-candlestickchart--docs)**: Financial candlestick chart with volume, moving averages, reference lines, and brush.
- **[GeomapChart](/docs/data-display-geomapchart--docs)**: Interactive geographic map for rendering GeoJSON/TopoJSON data with tooltips, zoom, choropleth, and markers.
- **[HeatmapChart](/docs/data-display-heatmapchart--docs)**: Heatmap matrix with CSS grid and color-mix for smooth interpolation.
- **[LineChart](/docs/data-display-linechart--docs)**: Line chart with gradient areas, stacked areas, reference lines, and brush.
- **[PieChart](/docs/data-display-piechart--docs)**: Pie/donut chart with interactive center label, legend, and outer slice labels.
- **[RadarChart](/docs/data-display-radarchart--docs)**: Radar/spider chart for multivariate data with polygon or circular grid.
- **[RadialChart](/docs/data-display-radialchart--docs)**: Radial bar chart with concentric rings and semicircular gauge mode.
- **[ScatterChart](/docs/data-display-scatterchart--docs)**: Scatter/bubble chart with trend lines, multi-series, and brush.
- **[TreemapChart](/docs/data-display-treemapchart--docs)**: Treemap with hierarchical drill-down, breadcrumb navigation, and aspect ratio control.

#### Feedback

## 📦 Installing Components

### Via `@lema-ufpb/ds-sync` (recommended for UFPB projects)

For institutional projects, use our dedicated CLI on [npm](https://www.npmjs.com/package/@lema-ufpb/ds-sync) with auth, lockfile, drift detection, and CI support:

```bash
npm install -D @lema-ufpb/ds-sync
```

Configure in `.env.local`:

```env
LEMA_DS_TOKEN=<your-token>
LEMA_DS_REGISTRY=https://ds.lema.ufpb.br
```

Common commands:

```bash
npx ds add dashbox bar-chart        # Install component(s)
npx ds update progress-bar          # Update component(s)
npx ds verify                       # Drift detection
npx ds sync --all --yes             # CI mode
```

> 🔑 Token provided by LEMA's NOC. Lockfile `ds.lock` is auto-generated and **must be committed**.

### Via shadcn CLI

Any component can also be added directly via the standard shadcn CLI:

```bash
npx ds add <component-name>

# Examples:
npx ds add dashbox
npx ds add progress-bar
npx ds add search-combo
```

> The shared i18n dictionary (`lib/ui-i18n.ts`) is automatically installed as a registry dependency for every locale-aware component.

## 🌐 Internationalization

Components display UI labels (tooltips, aria-labels, status text, empty state messages) based on the `locale` prop. The dictionary supports four locales:

| Code  | Language           |
| :---- | :----------------- |
| en-US | English (default)  |
| pt-BR | Português (Brasil) |
| es-ES | Español            |
| fr-FR | Fran&ccedil;ais    |

```tsx
import { Dashbox } from "@/components/ds/dashbox"
import { Counter } from "@/components/ds/counter"
import { DataTable } from "@/components/ds/data-table"

;<Dashbox title="Status" locale="pt-BR" status="live" />
{
  /* → Badge: "Online", toolbar: "Atualizar", "Recolher", ... */
}

;<Counter locale="es-ES" defaultValue={5} />
{
  /* → aria-label: "Contador", buttons: "Disminuir valor" / "Aumentar valor" */
}

;<DataTable locale="pt-BR" data={rows} columns={cols} pagination />
{
  /* → busca: "Buscar…", empty: "Nenhum dado encontrado", paginação: "Anterior" / "Próximo" */
}
```

The `locale` prop defaults to `"en-US"` when omitted. Extending to additional locales requires only adding a new entry to `UI_I18N` in `lib/ui-i18n.ts`.

## 🌟 Key Features

- **Accessibility (a11y)**: Every component follows WAI-ARIA guidelines with full keyboard navigation support. See our [Accessibility Statement](/docs/ui-accessibility--docs) for WCAG 2.1 AA compliance details.
- **Dark / Light themes**: All colors use shadcn semantic tokens and adapt automatically via CSS variables.
- **Responsiveness**: Mobile-first approach — complex components like `FooterMenu` switch layouts based on viewport.
- **Type Safety**: 100% TypeScript with CVA-powered variant props for a bulletproof developer experience.
- **Registry-ready**: Each component is individually registered in `registry.json` (type `registry:ui` or `registry:lib`) and installable via `npx ds add <component-name>` without copying the repo. Barrel entries aggregate sub-components as `registryDependencies` for bulk install.
